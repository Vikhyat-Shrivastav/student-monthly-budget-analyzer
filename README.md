# Student Monthly Budget Analyzer

## Project Overview
The **Student Monthly Budget Analyzer** is a beginner-friendly Python command-line project designed to help students understand and manage their monthly income and expenses.

The program takes monthly income and different expense amounts as input, calculates total expenses, remaining balance, and savings rate, and displays a clear monthly budget report.

## Features
- Takes student name as input.
- Accepts monthly income.
- Calculates food expenses.
- Calculates travel expenses.
- Calculates study material expenses.
- Calculates mobile and internet expenses.
- Calculates other expenses.
- Calculates total monthly expenses.
- Calculates remaining balance.
- Calculates savings rate and expense percentages.
- Displays a formatted monthly budget report.

## Technologies Used
- Python 3
- Built-in Python functions
- Command Line Interface (CLI)

## Python Concepts Used
- Variables and Data Types
- User Input (`input()`)

## How to Run the Project

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd student-monthly-budget-analyzer
```

3. Run the Python program:

```bash
python main.py
```
